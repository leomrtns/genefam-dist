\section{Methods}

\subsection{Inputs and tree signatures}

Let $G_j$ be an unrooted gene tree whose leaves are gene copies, each mapped to a species label. Multiple leaves may map
to the same species, and species may be absent. Let $\mathcal{R}=\{R_1,\ldots,R_L\}$ be an ordered collection of rooted
reference species-tree topologies. Every reference tree contains the same full species set, which must include every
species represented in $G_j$. Reference branch lengths are not used by the current dissimilarities.

For an ordered collection of $K=6$ dissimilarities, the unnormalised tree signature is
\begin{equation}
  \mathbf{v}(G_j;\mathcal{R}) =
  \left(d_i(G_j,R_\ell)\right)_{\ell=1,\ldots,L;\ i=1,\ldots,K}.
  \label{eq:signature}
\end{equation}
The implementation orders the six values for each reference tree as duplication, loss, deep coalescence,
Robinson--Foulds (RF), Hdist, and approximate subtree-prune-and-regraft (SPR). The resulting vector has $6L$
coordinates. Reference topologies that are identical under the parser's rooted-tree convention are stored once, so $L$
is the number of distinct parsed reference topologies.

The native Python interface represents parsed Newick data as reusable \texttt{TreeSpace} objects. A call uses the first
distinct gene topology and every distinct reference topology. Thus, a posterior sample or bootstrap distribution is
currently represented by projecting its trees separately; the software does not yet define a family-level aggregation
of multiple topologies. The parsed objects are retained across calls, while calculation-specific copies protect them
from algorithms that temporarily alter reconciliation or topology state.

\subsection{Dissimilarities}

Three reconciliation scores are inherited from the LCA-mapping calculations used by \textit{guenomu}
\citep{Martins2016}: the minimum number of duplications, losses, and deep coalescences. Gene-tree root position is not
assumed to be known. The implementation evaluates possible gene roots and retains the minimum reconciliation score; the
reference species tree remains rooted.

The remaining scores use an extended species tree, following the construction used by mulRF
\citep{Chaudhary2015MulRF}. Each species leaf is replaced by a multifurcation containing the gene-copy leaves mapped to
that species. The extended species tree and the gene tree then have a one-to-one leaf mapping. RF is the unrooted
Robinson--Foulds distance between these trees. Hdist sums split-matching costs obtained through a minimum-cost assignment,
and the SPR score is an approximation based on the same split matching. These three calculations ignore the reference
root. All six scores use topology but not branch lengths.

Although we use the convenient term \emph{dissimilarity}, the gene--species scores are not metrics on a common tree
space: their arguments have different roles, and symmetry and the triangle inequality are not generally applicable.

\subsection{Normalisation}

The software exposes three output modes. The unnormalised mode returns Equation~\ref{eq:signature}. The default rescaled
mode divides each score by an implementation-defined upper bound $u_i(G_j)$ based on gene-tree size, species coverage,
and the corresponding split representation:
\begin{equation}
  s_i(G_j,R_\ell) = \frac{d_i(G_j,R_\ell)}{u_i(G_j)}.
  \label{eq:theoretical-rescale}
\end{equation}
This mode returns $6L$ values and requires no randomisation.

An optional randomisation mode returns two consecutive $6L$ blocks. For each observed score it first computes an
empirical lower-tail rank against the other observed reference scores and $Q$ randomised gene--species comparisons:
\begin{equation}
 p_i(G_j,R_\ell) =
 \frac{
   \sum_{r\ne\ell} I\!\left[d_i(G_j,R_r)\le d_i(G_j,R_\ell)\right]
   + \sum_{q=1}^{Q} I\!\left[\widetilde d_{ijq}\le d_i(G_j,R_\ell)\right]
 }{L-1+Q},
 \label{eq:empirical-rank}
\end{equation}
where $I[\cdot]$ is the indicator function and $\widetilde d_{ijq}$ is obtained after randomising both the working gene
and species topology. The second block rescales the observed score using the minimum and maximum across the observed and
randomised comparisons for gene tree $G_j$:
\begin{equation}
 m_i(G_j,R_\ell) =
 \frac{d_i(G_j,R_\ell)-a_{ij}}{b_{ij}-a_{ij}}.
 \label{eq:empirical-rescale}
\end{equation}
When $a_{ij}=b_{ij}$ within numerical tolerance, the implementation returns one for that coordinate. We call
Equation~\ref{eq:empirical-rank} an empirical rank rather than a calibrated $p$-value because the reference trees and
randomised comparisons do not necessarily constitute exchangeable draws from a specified null distribution.

\subsection{Choice of reference trees}

For $N$ labelled species there are $(2N-3)!!$ rooted binary topologies, already more than $10^7$ for $N=10$. Exhaustive
use is neither possible nor desirable. The reference collection should instead span alternatives relevant to the
observed gene families and the scientific question. Candidate sources include posterior or bootstrap samples of species
trees, optima inferred from subsets of genes, deliberate perturbations around such trees, and random trees used as
negative controls.

A small reference set reduces dimension and computation, but can map distinct gene histories to similar signatures. A
large or redundant set increases cost without necessarily adding information. Because the resulting geometry is
conditional on $\mathcal{R}$, reference selection should be assessed by sensitivity analyses: repeat the downstream
analysis across independently selected reference sets, compare informed and random landmarks, and reserve gene families
not used to construct $\mathcal{R}$ when evaluating out-of-sample behaviour.

\subsection{Downstream analyses}

Tree signatures form a conventional design matrix with one row per projected gene tree and one column per
reference-tree--dissimilarity combination. Standard dimension-reduction, clustering, and supervised-learning methods can
therefore be applied. These downstream procedures do not turn the coordinates into independent observations, and a
visual cluster is not by itself evidence for a distinct biological process. Feature loadings can nevertheless be traced
back to particular dissimilarities and reference trees.
